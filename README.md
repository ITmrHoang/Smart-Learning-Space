# Smart-Learning-Space

A smart, technology-integrated learning environment connecting teachers and
students.

## Learning Space demo

The current project is a responsive, dependency-free web demo with:

- A shared overview of classes, upcoming work, and learning progress
- Student and teacher dashboard perspectives
- Classroom and assignment views with assignment filters
- A sample class conversation (messages stay in the current page and are not
  sent or saved)

The dashboard uses sample data and does not require an account.

To run it locally, open `index.html` in a browser or start a static server from
the repository directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
